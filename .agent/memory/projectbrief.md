# Project Brief: AdShield

## Overview
AdShield — это Android VPN-приложение для блокировки рекламы на уровне DNS. Приложение использует локальный VPN-сервис для перехвата DNS-запросов и блокировки рекламных доменов без необходимости root-доступа.

## Core Philosophy
**"Защита без компромиссов"**
- Блокировка рекламы на системном уровне (все приложения)
- Приватность: никакой телеметрии, все локально
- Простота: минимум действий для пользователя

## Core Objectives
1. **Эффективная блокировка** — высокий процент блокировки с минимумом ложных срабатываний
2. **Производительность** — минимальное влияние на батарею и скорость
3. **Монетизация** — Free vs Premium модель с разумными ограничениями
4. **Красивый UI** — CyberPunk эстетика, премиальный вид

## Key Features
- **VPN-based DNS filtering** — блокировка на уровне DNS запросов
- **Hosts + Regex фильтры** — гибкая система правил
- **App Whitelisting** — исключение приложений из фильтрации
- **Real-time Stats** — графики и статистика блокировок
- **Premium Features** — расширенные фильтры, неограниченные обновления

## Target Audience
- Пользователи Android, которые хотят заблокировать рекламу без root
- Люди, заботящиеся о приватности
- Технически подкованные пользователи (CyberPunk тема)
